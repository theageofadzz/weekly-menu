# 一人食 · 食材保鲜记录

一个面向个人使用的静态食材采购与保鲜记录工具。记录采购规格、生产日期、保存方式和截止日期，按本地日历日计算保鲜倒计时，并支持 JSON 备份与恢复。

## 项目功能

- **库存视图**：查看在库食材、截止日期和剩余天数。
- **本次采购筛选**：单独查看 2026 年 11 月 3 日订单截图对应的 4 项食材。
- **保鲜倒计时**：按包装到期日和自定截止日中较早的日期计算。
- **日期记录**：支持购买日期、生产日期、开封日期、包装到期日和自定截止日。
- **状态管理**：食材可以标记为吃完或丢弃，也可以恢复到库存。
- **搜索与排序**：按食材名称、商店、备注搜索，支持按截止日、购买日期、价格或名称排序。
- **JSON 备份**：导出当前记录，或合并导入其他备份。
- **本地保存**：记录保存在当前浏览器的 `localStorage`，无需账号和后端服务。

## 数据规则

- **保质期不等于倒计时**：只有填写具体包装到期日或自定截止日后，页面才开始倒数。
- **截止日取较早值**：包装到期日和自定截止日同时存在时，使用较早日期。
- **生产日期单独保存**：生产日期不会自动推算购买日、保质期或到期日。
- **日期校验**：购买、开封和截止日期不能早于生产日期；包装到期日不能早于购买日期。
- **历史采购保留**：吃完或丢弃的记录仍计入采购金额，并可在购买记录中恢复。
- **补录只执行一次**：旧浏览器记录启动时会通过固定批次编号补入本次 4 项，避免重复添加。
- **保留用户修改**：补录不会覆盖已有数量、日期、备注、状态或删除结果。
- **容量限制**：最多保存 5000 项记录；超过上限时不会自动补录。

## 本地开发

项目是无需构建工具的静态页面，使用 Node.js 运行测试。

```bash
npm ci
npm test
```

本地预览可以直接打开 `index.html`，也可以使用任意静态文件服务器：

```bash
npx serve .
```

主要文件：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、表单和对话框 |
| `style.css` | 响应式界面样式 |
| `app.js` | 页面交互、筛选、编辑、导入导出 |
| `core.js` | 数据校验、日期计算、批次补录和统计 |
| `tests/` | 核心逻辑与 DOM 交互测试 |

## 数据与隐私

- 数据只保存在当前浏览器的 `localStorage`。
- 存储键为 `weekly-menu-food-journal-v1`。
- 不使用账号、后端数据库、外部数据服务或后台通知。
- 不同浏览器和设备之间不会自动同步。
- 建议定期使用“导出备份”保存 JSON 文件。
- 导入备份时，相同编号保留 `updatedAt` 较新的记录。
- 读取到损坏数据时会停止写入，并保留原始内容供导出恢复。

## 食品安全说明

页面倒计时只是个人整理工具，不代表食材仍然安全可食用。实际使用时，包装说明、冷链情况、开封要求、保存温度、气味和外观异常优先。

个人计划截止日与包装保质期分开记录，不能用个人计划截止日替代食品标签或官方说明。
